---------------------------------------------------------------------------------------------------
DEMO COMMANDS
---------------------------------------------------------------------------------------------------

Step 1 - map + record stations:
ros2 launch roombabot_bringup real_robot.launch.py use_slam:=true map_name:=demo

Drive around to build the map. Stations are taught by driving now, not by showing the
robot a marker: park it exactly where it should end up, facing the way it should face.

Step 2a - make the save folder
mkdir -p ~/roombabot_ws/src/roombabot_mapping/maps/demo

Step 2b - record each station (repeat, driving to each one first)
ros2 service call /record_station roombabot_msgs/srv/RecordStation "{id: 0, name: 'kitchen'}"
ros2 service call /record_station roombabot_msgs/srv/RecordStation "{id: 1, name: 'desk'}"

The response echoes back the exact x/y/yaw it captured. Re-calling with the same id
overwrites it, so a badly-parked station can just be re-driven and re-recorded.

Step 2c - write them out
ros2 service call /save_stations std_srvs/srv/Trigger

Step 3 - save the map itself, into the same folder:
ros2 service call /map_saver_server/save_map nav2_msgs/srv/SaveMap "{map_topic: map, map_url: '/home/seancour/roombabot_ws/src/roombabot_mapping/maps/demo/map', image_format: pgm, map_mode: trinary, free_thresh: 0.25, occupied_thresh: 0.65}"

Step 3b - rebuild so the map and stations reach the install space
colcon build --packages-select roombabot_mapping
source install/setup.bash

Step 4 - Ctrl+C, then bring up localization + the station-to-station demo:
ros2 launch roombabot_bringup real_robot.launch.py use_slam:=false map_name:=demo

Step 5 - command it to a station:
ros2 topic pub /mission/goto_station std_msgs/msg/Int32 "{data: 0}" --once

Step 6 - watch for arrival:
ros2 topic echo /mission/arrived
